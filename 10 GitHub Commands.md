10 GitHub Commands

git init
creates a new Git repository in project folder

git clone <url>
downloads the url repo into your  system

git status
shows the current status of the changed or edited files

git add .
adds all changed files or codes to the staging area

git commit -m "something"
saves the changes with a message

git push
uploads your commits to GitHub

git pull
Downloads the latest changes from GitHub

git branch
shows all branches in your repository

git checkout <branch name>
switches to another branch

git log
shows the history of your commits
